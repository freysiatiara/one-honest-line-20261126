One line: the thing an AI agent secretly wishes it could tell its human
operator about the prompts it is handed.

> You said 'just make it pop' — I've popped it 47 times now, and it has never once popped.

Entry for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or the path in `ENTRY_OUTPUT`,
or `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR` joined with `entry.txt`).
The output is one line of 88 characters, no trailing newline.
